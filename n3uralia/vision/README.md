# N3uralia Vision Layer

## Purpose

Analyze an image before sending it to the Clarity enhancement pipeline.

The vision layer decides:

- what must be preserved
- what enhancement strategy is allowed
- which profile should be applied

## Initial categories

- portrait
- architecture
- nature
- artwork
- unknown

## Future models

- CLIP classifier
- vision language models
- segmentation models
- face identity analysis

## Philosophy

Enhance reality while preserving the original image identity.
